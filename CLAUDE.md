# Project Rules

## Working Rules
- Do not overengineer.
- Response must be concise, short, plain English only — no jargon.
- Implementation must match exactly what user describes, no extra scope.

## Frontend Theme
<always_use_editorial_theme>
Always design with an Editorial Western wedding aesthetic:
- Serif headline type (Playfair Display or similar) + clean sans body
- Neutral palette: cream, charcoal, one muted accent (sage/dusty rose/gold)
- Generous white space, magazine-grid layout
- Full-bleed photography, minimal borders
- Subtle scroll-reveal animations, no bounce/playful motion
</always_use_editorial_theme>
